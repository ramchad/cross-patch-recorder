Storage strategy

Data are buffered briefly, then written into IndexedDB in 5-minute (or 10-minute) CSV parts. This avoids keeping a full 30–60 minute recording in RAM. After Stop, export each part plus the session metadata.

Optional session info

Each CSV part continues the same global time and sample numbering. The next file does not restart at 0 s. This lets MATLAB join part01, part02, part03, etc. into one continuous recording.
For a 60-minute session with 4-minute auto-save, expect about 12 CSV parts. Each filename already includes subject, recording, protocol, condition, orientation, posture, date/time, and part number. The setup JSON is optional. MATLAB can concatenate them in order.
