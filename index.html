How the live estimate is calculated

The app averages the full-rate data to 10 Hz, uses the most recent 3 minutes, searches 2–4 CPM for the strongest combined CH1/CH2 sinusoidal component, estimates each channel amplitude from that component, and calculates the principal XY axis from the reconstructed simultaneous cycle.

Storage strategy

Data are buffered briefly, then written into IndexedDB in 5-minute (or 10-minute) CSV parts. This avoids keeping a full 30–60 minute recording in RAM. After Stop, export each part plus the session metadata.

Optional session info

For a 60-minute session with 5-minute auto-save, expect about 12 CSV parts. Each filename already includes subject, recording, protocol, condition, orientation, posture, date/time, and part number. The setup JSON is optional. MATLAB can concatenate them in order.
